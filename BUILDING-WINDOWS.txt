Dylan's Optimized SRB2 Build V1.6.0 - Windows source

Use a 64-bit MinGW-w64 toolchain with GCC, GNU Make, gendef, dlltool, and
windres. This build uses w64devkit 2.11.0.

Pass the matching Windows release folder containing the bundled DLLs.

    & '.\Build Windows Client.ps1' -RuntimeDirectory 'C:\path\to\Windows release'

If the toolchain is outside PATH, also pass -ToolchainBin.

    & '.\Build Windows Client.ps1' -RuntimeDirectory 'C:\path\to\Windows release' -ToolchainBin 'C:\path\to\toolchain\bin'

The script temporarily maps a drive letter when the source path contains
spaces. It builds bin\srb2win.exe and bin\srb2win.exe.debug. Keep the debug
symbols and license notices with the release.

Start with srb2win.exe. It restores missing bundled DLLs next to the
executable before loading them. If the official SRB2 2.2.15 base game data
is missing, it downloads and verifies the required data files.
